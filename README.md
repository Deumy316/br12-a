# BR-A 제출 전 확인

1. docs의 [입력] 표시(회사명, 재직기간, 연락처)를 실제 정보로 수정
2. 10번 논문 DOCX/PDF 포함 및 사이트 연결 완료
3. 13번 앱 완료 후 예약 카드 교체
4. renewal-device에서 `python update.py` 두 번 실행해 같은 해시 확인
5. records.json에 새 기록 1개를 반영해 숫자 변경 확인
6. 사이트를 Vercel/GitHub Pages 등에 HTTPS로 공개
7. 시크릿 창에서 로그인 없이 URL이 열리는지 확인

## 제출 확인 문구
- 무엇: 공개 사이트의 자기소개, 13주 숫자, 대표작, 지원 문서와 갱신 장치를 확인합니다.
- 어디: 제출한 HTTPS 결과물 URL과 ZIP의 README에서 확인합니다.
- 통과: 이름·한 줄 소개·날짜 있는 장면·출처 있는 숫자·10번 논문 자리·13번 앱 자리·3개 지원 문서·재실행 가능한 갱신 장치가 보이면 통과입니다.

## AI와 내 판단
- AI에게 맡긴 일: 문서 초안, 페이지 구조, 갱신 코드와 형식 정리를 맡겼습니다.
- 내가 판단한 일: 공개할 실제 경험, 강점, 대표작, 경력 내용과 최종 표현을 선택했습니다.
- AI 말을 안 들은 일: 실제 경험과 맞지 않거나 과장된 표현은 사용하지 않고 사실에 맞게 수정했습니다.

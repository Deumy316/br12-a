# 갱신 장치 실제 테스트 결과

실행 환경: Windows PowerShell

## 동일 입력 재실행
`py update.py`를 같은 입력으로 두 번 실행.

두 번 모두:
- 아침 기록: 36
- 마무리 기록: 35
- 완료 프로젝트: 2
- 동일 입력 확인용 해시: `63d4559dead2e794`

판정: 동일 입력 → 동일 결과 확인.

## 입력 변경 테스트
`input/records.json`의 아침 기록을 36 → 37로 변경 후 실행.

결과:
- 아침 기록: 37
- 마무리 기록: 35
- 완료 프로젝트: 2
- 동일 입력 확인용 해시: `c568a315f2a32f5a`

판정: 입력 변경 → 출력 및 해시 변경 확인.

## 원복 테스트
아침 기록을 37 → 36으로 되돌린 후 실행.

결과:
- 아침 기록: 36
- 마무리 기록: 35
- 완료 프로젝트: 2
- 동일 입력 확인용 해시: `63d4559dead2e794`

판정: 원래 입력으로 복귀 → 원래 결과로 복귀 확인.
